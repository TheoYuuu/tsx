# 架构

TSX 使用 Swift 6、AppKit、SwiftUI、Apple Translation、Vision 与 ScreenCaptureKit。当前构建为 macOS 官网直接分发；[分发边界](Distribution.md)规定身份、权限与签名，[验证摘要](Validation.md)说明实际覆盖范围。

## 数据流与职责

用户触发 → 选中文字、输入或 OCR → 翻译协调器 → 所选 Provider → 主工作区或临时截图结果层的翻译模型。

| 目录 | 职责 |
| --- | --- |
| `TranslateX/App` | 生命周期、菜单栏、服务装配及截图意图协调 |
| `TranslateX/Windows` | 主窗口、权限提示、区域选择、临时截图结果层、定位、焦点及退出事件 |
| `TranslateX/Translation` | 请求身份、语言、结果、取消、Apple 会话桥接 |
| `TranslateX/Translation/Services` | 用户配置、Keychain、HTTP、流解析、账号会话和用量 |
| `TranslateX/System` | 权限、取词、快捷键、截图、OCR 与更新 |
| `TranslateX/Settings` | 偏好、快捷键和旧偏好域兼容导入 |
| `TranslateX/UI` | 共用编辑、结果、设置和状态内容 |
| `Runtime/CodexHelper` | 独立账号主管与短生命周期 worker |

AppKit 集中管理窗口，SwiftUI 负责内容。系统服务只在实际能力边界注入，不放入 View；渠道选择集中于应用装配入口。Debug/Release 是构建模式，不代表分发渠道。

## 翻译状态与编辑

`TranslationModel` 区分空内容、语言准备、处理中、成功、失败和取消。每个意图有身份；输入快照、服务修订和账号代际共同阻止旧结果覆盖当前内容。UI 更新在 MainActor，耗时系统工作不占主线程，Swift 6 严格并发检查保持开启。

两侧使用原生 NSTextView，保留选择、组合输入、编辑菜单和撤销。最后主动编辑的一侧决定请求方向，停顿 650 ms 后按自动设置调度；未提交的 marked text 不发请求。程序写回、复制、撤销和恢复上一条不经过主动输入入口，避免双向循环。外部服务默认手动，切换服务或保存配置不自动发送正文。

无 Unicode 字母的数字、符号和表情可原样同步，不创建 Provider 请求。同语言同步必须基于实际文字判断，不能只因下拉框语言相同就跳过翻译。自动检测针对仍需翻译的文字；明确源语言优先，低置信短标签仍可能误判，保留手选语言退路。

人工编辑和流式片段是可编辑内容，只有匹配当前请求的完成响应才成为完成结果。停止或失败保留已有文字并标明状态，不自行重试。清空、交换与成对撤销使用内存快照，不触发请求；原生文本撤销仍由编辑器负责。未知系统错误不直接展示，以免回显正文。

原文与译文的朗读由独立系统服务管理，通过 macOS 本地语音合成，仅在点击喇叭时开始；与所选翻译 Provider 无关，不自动播放。英语口音统一记忆为美式或英式，严格使用对应地区的可用系统声音，缺失时明确提示，不跨口音替换，也不使用个人或趣味声音。播放期间喇叭保留并显示声波动效，减少动态效果时只显示高亮；再次点击立即停止，下次从头朗读。同一时间仅播放一侧，编辑、流式文字变化、交换、清空、切换口音及窗口关闭、隐藏或退出都会停止旧朗读；请求身份阻止迟到回调影响新播放。语言未明确时对有界文字样本进行本地识别，不创建翻译请求。

Apple Provider 只在有效 `translationTask` 会话中创建，不跨视图生命周期保留 Session。输入与取词共用 `inputModel` 和主窗口编辑器；临时截图层持有短期 `TranslationModel` 和自己的 `AppleTranslationHost`，关闭时取消请求并释放图片。权限提示不挂载翻译宿主，也不持有翻译模型。

外部取词交付内容，或用户主动将截图送入主窗口时，先结束组合输入并在内存中保留最近一条可恢复快照，再替换当前工作区。快照包含两侧内容、图片及区域、语言、来源和可复用的完成结果，不保存活动请求或系统会话；空内容与尚未交付文字的重复识别不会覆盖已有的有效快照。恢复会取消当前工作并消耗这条快照，未完成请求转为停止，不自动重发正文；服务修订变化后也不把旧结果当作当前服务的新完成结果。权限失败、取消框选和临时截图结果不替换主窗口内容。同一截图在浮层与主窗口间重复往返时保留最初的恢复快照；返回浮层携带当前编辑内容、语言及原图，保留拖动位置、显示尺寸和工具条方向，不重新识别或发送翻译请求。返回入口仅适用于当前截图，新内容交付、清空或恢复上一条后失效；取消新框选和收起主窗口不使其失效。

## 窗口、本地化与退出

只有一个完整翻译工作区，输入、取词及主动移入的截图在主窗口编辑；来源位于左上角交通灯按钮右侧，「恢复上一条」与适用时的「返回悬浮窗」位于标题栏右侧，标题栏左右边缘与下方内容外框对齐。快捷取词沿用主窗口 `.main` 的尺寸记忆，横纵布局分别保存，显示时限制在屏幕可见范围；布局切换保留编辑器身份、组合输入和撤销。截图默认使用选区附近的临时图片层，设置和权限提示使用各自窗口。

翻译窗口失焦不自动关闭。Esc 收起主窗口、取消当前操作，并在来源应用仍可用时将焦点交还；菜单跟踪、系统表单、输入法组合输入和更新弹窗各自优先处理 Esc。当前正文、图片、来源和上一条恢复快照仅存在于进程内，退出后不保存为历史。

权限提示使用系统标题栏与原生关闭、最小化和缩放按钮；普通 AppKit 内容容器内嵌 SwiftUI，避免内容布局重写窗口尺寸约束。标准缩放限制为紧凑尺寸并保留系统的再次缩放恢复行为。权限来源独立于主工作区；主动关闭且提示仍为当前键窗口时才交还来源，转入主窗口或设置时不抢回焦点。

`AppPreferences.interfaceLanguage` 支持跟随系统、简体中文和 English。`L10n` 维护有效语言；稳定宿主注入 locale，原生菜单、标题与可访问标签按需刷新。不重建编辑器或翻译会话，不改系统语言，也不重新读取密钥或注册快捷键。正文、服务名与外部返回内容不参与字符串反向匹配。

正常退出先封锁新工作、取消翻译、移除监听，再通过 AppKit 延迟退出等待取词收尾和账号进程回收。普通退出保留已提交账号；强制退出不保证剪贴板恢复或未完成用量记录落盘。

## 取词与剪贴板

取词仅由快捷键或菜单主动触发。先固定来源应用并尝试 AX，再在授权、来源和时序都符合时使用受控复制兜底；已有剪贴板不能冒充当前选区。

AX 与剪贴板 IPC 使用独立 actor；`SelectionEnvironment` 集中权限、前台、修饰键、AX 读取和复制边界。复制前等待松键，持续核对来源与取消；只向已确认来源投递复制事件，合成事件收尾清除自身 Command 标记。不能通过广播释放键或移除守卫掩盖异常。

剪贴板备份只短暂存在内存。一次复制只接受可归因的所有权变化；多次变化或外部新写入时停止读取/恢复，避免覆盖新内容。权限失效返回权限说明，不误报来源不支持。日志只包含固定阶段和错误码，不记录正文、剪贴板数据或来源应用身份。

## 截图与 OCR

`ScreenshotTranslationController` 唯一协调截图意图。区域选择只处理坐标和拖动；ScreenCaptureKit 在授权后分屏捕获，排除自身覆盖层，并按涉及屏幕的最高比例拼接。框选和抓取期间由布局保护器核对显示器布局，像素获取后停止该保护器；随后临时结果层比较真实屏幕几何变化，关闭坐标已失效的图片层。普通应用激活引起的屏幕通知不会误判为布局改变。

Vision 使用异步识别，取消传播到系统请求，同时由意图身份阻止迟到结果。系统首次初始化仍可能较慢。排序只保守支持横排自然段、明显列表和清晰多栏，不承诺复杂表格或竖排顺序。

图片、OCR 区域及归一化边界组成内存 `ScreenshotDocument`。首次松开框选后识别文字，依据当前服务的自动翻译偏好开始翻译或等待点击；从截图工具条重新框选时，先显示取消和确认按钮，确认后才抓取并翻译。区域按当前 Provider 串行翻译，只发送文字和语言。只有全部区域成功才形成完整结果。停止和失败保留已完成的部分，切换语言清除旧语言译文，语言交换保留图片及 OCR 原文。

`ScreenshotOverlayController` 将完整图片放在原选区位置，44 点高的单行工具条与图片间隔 8 点，在下方空间不足时移到上方；过大的选区等比适配屏幕，不裁去图片。服务独立成框，原文和目标语言共享边框；操作使用图标和文字提示，低频复制操作及主窗口交接放在更多菜单。进度、失败与溢出提示按需显示在图片上，不占永久状态行。Esc 关闭图片并返回来源应用，菜单和保存表单优先处理；显示器布局改变时关闭旧坐标图片层。

临时图片使用固定 `#B3CFF2`、1.5 点边框和 4 点圆角，不跟随主题或材质变化。按住图片可整体移动图片与工具条，保持尺寸、间距与工具条方向；图片上的全文和重试入口独立处理点击。拖动以屏幕坐标为锚点，将可容纳的内容限制在目标屏幕可见范围内；跨到较小屏幕而无法完整容纳时保留原比例，并将工具条所在边保持可见。预览更新不重置位置；边框与圆角只用于显示，不写入复制或保存的图片。

主窗口截图编辑区复用现有头部、图标、自动互译动效和横纵布局，两个内容栏统一使用 10 点内边距。原文栏切换图片／识别文字，译文栏切换可编辑文字／译图；图片区域通过稳定 ID 定位对应编辑器。源文字的自动更新及显式单段重译只请求该区域，保留其他区域的修改；单段完成不冒充整张图片的新完整翻译结果。文档另保留最近生成译文，供局部恢复、撤销和窗口交接使用，仍只驻留内存。保存从当前文档生成原始尺寸 PNG，不依赖延迟刷新中的预览。

`ScreenshotImageRenderer` 在原始像素上独立合成译图。对已有译文的 OCR 行采样周围背景与字色，修复行区域并用 CoreText 自动换行缩放；保留未处理区域及图片尺寸。文档、纯色和渐变背景是主要适用范围，不做生成式照片纹理修复。区域重叠或长文无法在可读字号下完整放入时，保留原图并明确提供全文入口，不以裁断内容冒充完整译图。临时层、主窗口原图模式和 PNG 输出共用此合成器；只有主动复制或保存才将文字／图片写入剪贴板或用户选择的文件，不导出工具条。

## 外部服务与凭据

配置、凭据和当前服务选择彼此独立。配置保存不会切换当前服务；删除已选配置回到 Apple。请求地址、模型、密钥或账号变化推进修订，撤销旧目录和旧请求，不重放正文。API Key 按配置 UUID 保存在应用 Keychain，地址变化不得把旧密钥带往新端点。

网络使用有界临时会话，不继承 cookie/缓存凭据，不自动跟随重定向、重试或切换备用地址。生产远程连接使用 HTTPS，本地服务仅在允许的本地地址边界开放 HTTP。输入、响应、事件和译文均有大小限制；截断、拒绝、工具输出及未完成流不能成为成功结果。取消客户端工作不保证服务商停止计算或免除费用。

服务编辑器维护独立草稿、字段错误、目录和样例任务。密钥存在性查询不返回秘密数据；明确查看时才读取，并在隐藏、失焦或离开时清除临时明文。样例使用固定构造文字，停止后等待原任务收尾；目录成功不等于模型可翻译。未保存草稿由统一导航协调器保护，截图暂时隐藏只暂停任务并隐藏密钥。

## 账号运行组件

新增服务提供 API 接入、本地模型和实验性 Codex / ChatGPT 登录。账号入口保留实验性标识；真实登录、模型目录与翻译的端到端验收范围见[验证摘要](Validation.md)。账号运行路径通过 Bundle 内 helper 使用固定版本的官方公开库，不启动 Agent、工具循环或 app-server，也不复用其他 Codex 应用的账号和配置。普通启动不读账号、不创建 helper；明确账号操作才使用共享 `CodexAccountController`。

账号根目录由 OS 用户数据库派生，沿用兼容目录名，不接受环境或 IPC 路径覆盖。每个操作持有排他 lease，worker 继承同一文件描述。凭据按随机代际存入独立 Keychain 项；`active.json` 是提交点，未确认清理的 journal 保留。模型/翻译必须匹配 `expected_generation`，不能转用新账号。

正式路径串联管理策略、账号资格、模型目录与官方工作区路由。单请求 worker 在约束无法落实时失败；刷新失败不退回旧令牌，模型请求不自动重发。原生会话必须收到终态、管道 EOF 与正常退出才接受结果。退出账号精确删除本地身份；远端撤销不能仅由本地清除推定。

构建只嵌入与源码及工具摘要一致的 helper；Xcode 不隐式下载或编译 Rust。Debug 使用宿主架构，Release 包含 arm64/x86_64，无 QA feature，许可随 App 提供。详见 [运行组件](../Runtime/CodexHelper/README.md)和[打包契约](../Tools/CodexRuntime/PACKAGING.md)。

## 数据与更新

原文、译文和截图不写磁盘历史、偏好或日志；用户主动导出的图片除外。偏好保存服务配置及本机用量数字；API 密钥使用不跨设备同步的 Keychain。`TranslationUsageStore` 按服务独立控制统计，记录请求时间、模型、用途、状态、耗时与已返回计数。近期明细最多保留 30 个自然日、10,000 条；更早或超出明细容量的指标先按服务、模型、用途和日期汇总，再从明细中移除，历史总量不会因此清零。明细与汇总作为同一版本化快照保存，兼容旧数组和全局开关；旧全局停用仅迁移到已有服务，新服务默认启用。暂停保留历史，清空删除明细及汇总但保留开关；关闭、清空和删除推进统计代际，阻止迟到结果恢复旧记录。未知计数不解释为零费用。

设置窗口使用六个左侧导航入口：常规、翻译服务、用量统计、快捷键、权限与关于。服务编辑和配置用量查询仍是页内二级页面，未保存草稿离开前确认；统计独立于服务查询。各页共用白底下拉、无悬停底色的开关和统一圆角确认框。

DeepSeek/DeepL 账户额度查询按服务保存启用、间隔和超时；默认间隔为 0，仅显式手动刷新。保存正间隔后由应用级调度器查询固定官方接口，离开设置不会停止已启用的自动查询。停用、修改配置或退出会取消旧请求；缓存仅存在内存并绑定配置修订。刷新失败可保留同代旧值；账户额度与本机请求记录不合成消费账单。

统计保存真实 HTTP 状态码，Apple 本地翻译或未收到 HTTP 响应时为空，不把业务失败伪装成状态码。Apple 不提供 Token 计数，其费用为免费；外部服务缺少计数或价格时不当作零。定价目录由用户显式从固定的 models.dev 公共接口刷新，仅发送无认证的目录请求，限时、限大小并拒绝重定向。定价列表仅展示受支持官方厂商的文本模型美元参考费率，过滤废弃、重复路由及不支持的分层价格，不受统计服务筛选限制；自动估算只精确匹配受支持的官方服务和模型，不推断代理费率。

界面以美元展示成本并保留两位小数，小于 0.01 美元的非零值显示为“<$0.01”，完整 Decimal 金额在悬停提示中展示，计算与存储不提前舍入。旧数据的其他币种不直接换成美元或参与美元总计，缺失部分标记为待计价或已知小计。请求开始时保存厂商身份与价格快照；刷新目录只补算近期明细中没有价格快照且计数充分的请求，并标记为使用当前参考价的补算估值，不改写已有费用及日汇总。缺少厂商身份的旧记录，仅在当前官方配置仍使用同一模型时允许补算；新记录明确保存不适用状态，避免代理配置后来变更为官方端点时误套价格。日汇总继续分别保留各币种与已报告数量，不跨币种直接相加。

AppDelegate 持有 `AppUpdateController`，封装 Sparkle 并与菜单、主窗口及关于页面共享。仅 Release 构建启用线上更新器；Debug 开发构建不检查、安装或修改更新偏好，避免发行包覆盖 Xcode 构建产物。Release 应用启动会检查新版本：自动更新关闭时仅探测，不下载或安装；开启时通过 Sparkle 完成下载、验证、安装与重新启动。发现更新后在主窗口右上方显示入口，点击可查看说明并确认安装；该入口的确认及进度显示在主窗口中央。关于页的「检查更新」仅探测；已知版本的「更新到 v…」直接下载并接续安装、重启，进度留在设置窗口，不再跳转或重复确认。直接安装意图绑定点击时显示的版本；候选版本变化或仅提供外部下载信息时仍展示说明。失败、取消及结束清除本次安装意图，重试由用户明确触发，不改变自动更新偏好。需要交接至主窗口时先经过设置草稿确认，确认期间不得提前挂载安装弹窗或启动自动安装；取消更新保留两侧文字和未确认的升级说明。入口动效在窗口不可见或失焦、悬停、键盘聚焦、模态展示及减少动态效果时暂停。用户手动更新前可查看发布说明；打开设置本身不检查更新。自定义界面不替代 Sparkle 的签名、授权或替换流程，系统画像仍关闭；独立更新域名的清单和下载包验证 Ed25519 签名，正式包另做 Developer ID 与 Apple 公证。

手动检查使用独立的紧凑弹窗，只呈现检查状态、进度与取消；检查失败的重试与关闭按钮尺寸一致。检查结束后，同一个模态位置替换为原有更新说明，两个内容视图不叠加。已是最新版本和手动检查失败继续使用紧凑弹窗，下载、安装及其失败状态仍使用既有界面。启动及说明探测的检查阶段失败只记录状态，不弹窗；显式记录检查来源与阶段，取消后的迟到错误不恢复弹窗，下载或安装失败不因界面暂时关闭而被误判为后台检查。

普通 Debug 启动不再强制预览更新内容。正式版本升级后显示本次发布说明，以“知道了”记录确认；近期更新可查看已发布版本。发布说明通过 Sparkle 的 `didFinishLoadingAppcast` 回调取得，仅接收 `signingValidationStatus == .succeeded` 的内容。清单内使用 plain-text 格式承载双语 Markdown，并与随包说明按版本合并；同一版本选最高有效 Build，已验签远程的有效字段优先，空字段不抹掉随包内容，真实发布时间不由构建时间替代。远程内容只存内存；失败保留已有说明。条目、总字节数和单条文本均受限，完整说明链接仍需通过 HTTPS 主机与路径白名单。打开或重试近期更新只复用正在进行的检查或调用信息探测，不下载或安装；没有单独 GitHub API 请求。测试与视觉夹具不启动线上更新器，版本及更新操作使用隔离的内存状态。更新不接触翻译正文、服务凭据或用量。
