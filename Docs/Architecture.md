# 架构

TSX 使用 Swift 6、AppKit、SwiftUI、Apple Translation、Vision 与 ScreenCaptureKit。当前构建为 macOS 官网直接分发；[分发边界](Distribution.md)规定身份、权限与签名，[验证摘要](Validation.md)说明实际覆盖范围。

## 数据流与职责

用户触发 → 选中文字、输入或 OCR → 翻译协调器 → 所选 Provider → 共用结果状态 → 主窗口或浮窗。

| 目录 | 职责 |
| --- | --- |
| `TranslateX/App` | 生命周期、菜单栏、服务装配及截图意图协调 |
| `TranslateX/Windows` | 主窗口、浮窗、区域选择、定位、焦点及退出事件 |
| `TranslateX/Translation` | 请求身份、语言、结果、取消、Apple 会话桥接 |
| `TranslateX/Translation/Services` | 用户配置、Keychain、HTTP、流解析、账号会话和用量 |
| `TranslateX/System` | 权限、取词、快捷键、截图、OCR 与更新 |
| `TranslateX/Settings` | 偏好、快捷键和旧偏好域兼容导入 |
| `TranslateX/UI` | 共用编辑、结果、设置和状态内容 |
| `Runtime/CodexHelper` | 独立账号主管与短生命周期 worker |

AppKit 集中管理窗口，SwiftUI 负责内容。系统服务只在实际能力边界注入，不放入 View；渠道选择集中于应用装配入口。Debug/Release 是构建模式，不代表分发渠道。

## 翻译状态与编辑

`TranslationModel` 区分空内容、语言准备、处理中、成功、失败和取消。每个意图有身份；输入快照、服务修订和账号代际共同阻止旧结果覆盖当前内容。UI 更新在 MainActor，耗时系统工作不占主线程，Swift 6 严格并发检查保持开启。

两侧使用原生 NSTextView，保留选择、组合输入、编辑菜单和撤销。最后主动编辑的一侧决定请求方向，停顿 650 ms 后按自动设置调度；未提交的 marked text 不发请求。程序写回、复制、撤销和窗口交接不经过主动输入入口，避免双向循环。外部服务默认手动，切换服务或保存配置不自动发送正文。

无 Unicode 字母的数字、符号和表情可原样同步，不创建 Provider 请求。同语言同步必须基于实际文字判断，不能只因下拉框语言相同就跳过翻译。自动检测针对仍需翻译的文字；明确源语言优先，低置信短标签仍可能误判，保留手选语言退路。

人工编辑和流式片段是可编辑内容，只有匹配当前请求的完成响应才成为完成结果。停止或失败保留已有文字并标明状态，不自行重试。清空、交换与成对撤销使用内存快照，不触发请求；原生文本撤销仍由编辑器负责。未知系统错误不直接展示，以免回显正文。

Apple Provider 只在有效 `translationTask` 会话中创建，不跨视图生命周期保留 Session。浮窗展开仅传两侧内容、语言、修订和可复用的完成结果；处理中交接转为停止，不携带会话、不重复发送外部请求。OCR 尚无正文时禁止展开，避免取消唯一识别意图。

## 窗口、本地化与退出

主窗口、浮窗和设置复用内容组件；布局切换保留编辑器身份、组合输入和撤销。窗口尺寸按窗口类型和横纵布局保存，显示时限制在屏幕可见范围。最近翻译窗口、正文和图片只在进程内恢复，退出后不保存为历史。

`AppPreferences.interfaceLanguage` 支持跟随系统、简体中文和 English。`L10n` 维护有效语言；稳定宿主注入 locale，原生菜单、标题与可访问标签按需刷新。不重建编辑器或翻译会话，不改系统语言，也不重新读取密钥或注册快捷键。正文、服务名与外部返回内容不参与字符串反向匹配。

正常退出先封锁新工作、取消翻译、移除监听，再通过 AppKit 延迟退出等待取词收尾和账号进程回收。普通退出保留已提交账号；强制退出不保证剪贴板恢复或未完成用量记录落盘。

## 取词与剪贴板

取词仅由快捷键或菜单主动触发。先固定来源应用并尝试 AX，再在授权、来源和时序都符合时使用受控复制兜底；已有剪贴板不能冒充当前选区。

AX 与剪贴板 IPC 使用独立 actor；`SelectionEnvironment` 集中权限、前台、修饰键、AX 读取和复制边界。复制前等待松键，持续核对来源与取消；只向已确认来源投递复制事件，合成事件收尾清除自身 Command 标记。不能通过广播释放键或移除守卫掩盖异常。

剪贴板备份只短暂存在内存。一次复制只接受可归因的所有权变化；多次变化或外部新写入时停止读取/恢复，避免覆盖新内容。权限失效返回权限说明，不误报来源不支持。日志只包含固定阶段和错误码，不记录正文、剪贴板数据或来源应用身份。

## 截图与 OCR

`ScreenshotTranslationController` 唯一协调截图意图。区域选择只处理坐标和拖动；ScreenCaptureKit 在授权后分屏捕获，排除自身覆盖层，并按涉及屏幕的最高比例拼接。选区至 OCR 交付期间持续核对显示器布局；布局改变使本次意图永久失效，要求重新框选。

Vision 使用异步识别，取消传播到系统请求，同时由意图身份阻止迟到结果。系统首次初始化仍可能较慢。排序只保守支持横排自然段、明显列表和清晰多栏，不承诺复杂表格或竖排顺序。

图片、OCR 区域及归一化边界组成内存 `ScreenshotDocument`。文字模式和原图模式共用状态；区域按当前 Provider 串行翻译，发送文字和语言，不上传截图。只有全部区域成功才形成完整结果。停止、失败、纠错和窗口交接保留已有区域与部分译文；长译文可在详情查看，不重建字体或修复图片背景。

## 外部服务与凭据

配置、凭据和当前服务选择彼此独立。配置保存不会切换当前服务；删除已选配置回到 Apple。请求地址、模型、密钥或账号变化推进修订，撤销旧目录和旧请求，不重放正文。API Key 按配置 UUID 保存在应用 Keychain，地址变化不得把旧密钥带往新端点。

网络使用有界临时会话，不继承 cookie/缓存凭据，不自动跟随重定向、重试或切换备用地址。生产远程连接使用 HTTPS，本地服务仅在允许的本地地址边界开放 HTTP。输入、响应、事件和译文均有大小限制；截断、拒绝、工具输出及未完成流不能成为成功结果。取消客户端工作不保证服务商停止计算或免除费用。

服务编辑器维护独立草稿、字段错误、目录和样例任务。密钥存在性查询不返回秘密数据；明确查看时才读取，并在隐藏、失焦或离开时清除临时明文。样例使用固定构造文字，停止后等待原任务收尾；目录成功不等于模型可翻译。未保存草稿由统一导航协调器保护，截图暂时隐藏只暂停任务并隐藏密钥。

## 账号运行组件

实验性 Codex / ChatGPT 入口通过 Bundle 内 helper 使用固定版本的官方公开库，不启动 Agent、工具循环或 app-server，也不复用其他 Codex 应用的账号和配置。普通启动不读账号、不创建 helper；明确账号操作才使用共享 `CodexAccountController`。

账号根目录由 OS 用户数据库派生，沿用兼容目录名，不接受环境或 IPC 路径覆盖。每个操作持有排他 lease，worker 继承同一文件描述。凭据按随机代际存入独立 Keychain 项；`active.json` 是提交点，未确认清理的 journal 保留。模型/翻译必须匹配 `expected_generation`，不能转用新账号。

正式路径串联管理策略、账号资格、模型目录与官方工作区路由。单请求 worker 在约束无法落实时失败；刷新失败不退回旧令牌，模型请求不自动重发。原生会话必须收到终态、管道 EOF 与正常退出才接受结果。退出账号精确删除本地身份；远端撤销不能仅由本地清除推定。

构建只嵌入与源码及工具摘要一致的 helper；Xcode 不隐式下载或编译 Rust。Debug 使用宿主架构，Release 包含 arm64/x86_64，无 QA feature，许可随 App 提供。详见 [运行组件](../Runtime/CodexHelper/README.md)和[打包契约](../Tools/CodexRuntime/PACKAGING.md)。

## 数据与更新

原文、译文和截图不写磁盘历史、偏好或日志。偏好保存服务配置及本机用量数字；API 密钥使用不跨设备同步的 Keychain。`TranslationUsageStore` 仅保留最近 30 天、最多 10,000 条请求时间、模型、用途、状态、耗时与已返回计数；关闭、清空和删除推进统计代际，阻止迟到结果恢复旧记录。未知计数不解释为零费用。

DeepSeek/DeepL 账户额度只在明确刷新时查询固定官方接口，缓存仅存在内存并绑定配置修订。刷新失败可保留同代旧值；账户额度与本机请求记录不合成消费账单。

AppDelegate 持有 `AppUpdateController`，封装 Sparkle 并与菜单和设置共享；测试/预览不启动更新器。自动检查和下载默认关闭，系统画像关闭；官网清单和下载包均验证 Ed25519 签名，正式包另做 Developer ID 与 Apple 公证。更新不接触正文、服务凭据或用量，退出前提示保留所需内容。
